## B. 인스타그램 연동 — 계정 개설 후 진행 순서 (계획서 29쪽, S6)
1. 전문계정 전환 + 프로필 링크에 `travel.jawsweb.site` 등록 (댓글 없이도 허브로 갈 수 있게 **먼저**)
2. Meta 개발자 앱 생성 → Instagram 제품 추가 → 필요한 권한·웹훅 설정 (대표님 계정으로 직접)
3. 그 다음 단계에서 제가 만들 것: 웹훅 수신 → 콘텐츠 식별 → 1회 비공개 답장 → 발송 이력·중복 차단
4. 비공개 답장은 **허브 동선이 검증된 뒤** 선택 기능으로 켭니다

## C. 첫 콘텐츠 전 준비 (계획서 49쪽 착수 승인 묶음)
- [ ] 역할 지정: 제품 책임 / 편집 책임 / 기술 / 제휴 / 운영 — `trip.staff`에 등록 (겸임 시 승인자는 제작자와 다르게)
- [ ] 첫 숙소 1곳 자료 요청: 객실 유형별 사진 원본, 촬영 시점, 시설 운영 안내, **사용 허락 범위와 철회 창구**
- [ ] 원작자 1명 협력: 자막 제공·요약 범위·원문 표시 방식 합의
- [ ] 실제 구독·도구 조건 확인표 작성 (edge-tts 음성의 상업 이용 조건 포함)
- [ ] 제휴 고지 문구와 개인정보 문의 양식은 실행 전 전문 검토 (계획서 42~43쪽)
