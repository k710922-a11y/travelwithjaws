# Travel.with.Jaws — 착수 키트 v0.3

서비스 주소: https://travel.jawsweb.site · 바다에서 도시까지, 확인하고 떠나는 여행

「여행 쇼츠·메타리뷰 플랫폼 사업계획서(2026.10.18)」의 **착수 1~30일 범위**를 코드로 옮긴 것입니다.
원칙은 계획서와 같습니다: *권리·근거·승인 기록이 없으면 공개되지 않는다.*

```
travelwithjaws/
├─ db/
│  ├─ migrations/001_core.sql     장소·자산(권리)·근거·주장·작업·버전·공개이력·정정 + 상태전이 트리거
│  ├─ migrations/002_access.sql   익명 사용자는 '공개 뷰'만 읽고 이벤트만 기록
│  ├─ migrations/003_portal.sql   미니 포털: 매체 출처·콘텐츠·컬렉션, 요약·썸네일 권리 규칙, 공개 피드
│  ├─ migrations/004_longform.sql 롱폼 = 쇼츠 묶음: 묶음 태그, 후보 자동 판정, 승인 차단, 권리 재확인
│  ├─ seed/test_rules.sql         제작·공개 차단 규칙 검증 (21건)
│  ├─ seed/test_portal.sql        포털 규칙 검증 (12건, test_rules 다음에 실행)
│  └─ seed/test_longform.sql      롱폼 묶음 기준 검증 (11건, 빈 DB에서 단독 실행)
├─ pipeline/
│  ├─ render_short.py             승인 자산 → 1080×1920 쇼츠 후보 + 자막 + 품질검사
│  └─ samples/                    예시 이미지·작업 매니페스트 (실제 숙소 아님)
├─ hub/                           Next.js 웹허브 — 홈은 미니 포털, /p/[작업번호]는 판단 문서 (Coolify용 Dockerfile 포함)
│  ├─ components/heroScene.js    해변·현수교·도시 스카이라인이 움직이는 히어로 장면 (캔버스, 이미지 파일 없음)
│  ├─ components/portal.js       포털 화면 로직 (매체 탭·바다↔도시 다이얼·컬렉션·테마·상세 시트)
│  └─ app/portal.css             포털 디자인 토큰 (라이트·다크)
├─ integrations/youtube/
│  └─ publish.py                  YouTube 공식 업로드: 쇼츠(upload/verify), 롱폼(longform) — 모두 비공개 → 사람 확인 → 공개
└─ docs/

   └─ CHECKLIST.md                대표님이 직접 해야 하는 일 / 착수 승인 체크리스트
```

## 이 키트가 막아 주는 것 (실제 Postgres 16에서 검증)

| 규칙 | 계획서 | 결과 |
|---|---|---|
| 증빙·철회경로·제삼자 점검 없이 자산 '승인' 불가 | 19쪽 | 차단 |
| 자막·구간·원작자 없는 후기 근거는 '확인완료' 불가 | 16쪽 | 차단 |
| 접수 → 승인 직행 등 허용되지 않은 상태 전이 | 38쪽 | 차단 |
| 권리 미확인 자산이 섞인 작업은 제작 대기 불가 | 35쪽 | 차단 |
| 합성 파일 없이 검수, 제작자 본인 승인 | 41쪽 | 차단 |
| 근거 미확인 핵심 주장이 있으면 승인 불가 | 17쪽 | 차단 |
| 허용 매체가 아닌 채널 배포 / 같은 버전 중복 게시 | 24쪽 | 차단 |
| 사람 확인 없이 '공개' 처리 | 24쪽 | 차단 |
| 자산 철회 → 연결 작업 자동 보류, 허브에서 즉시 제외, 업로드분 '수정 필요' | 37쪽 | 자동 |
| 의료 관련 장소 공개 | 44쪽 | 차단 |

## 빠른 시작 (PC에서)

```bash
# 1) 웹허브 데모 (DB 없이 예시 데이터)
cd hub && npm install && npm run dev        # http://localhost:3000/p/TRP-00001

# 2) 쇼츠 후보 합성 (ffmpeg 필요)
pip install edge-tts "psycopg[binary]"
cd pipeline && python render_short.py samples/job_TRP-00001.json --out renders
#   → renders/TRP-00001_v1_ko.mp4 / .srt / .json(해시·자산·품질검사)
#   권리 미확인 자산이 있으면 exit 2로 합성 거부, 품질검사 실패면 exit 3
```

## 아직 하지 않은 것 (의도적으로 보류)

- **인스타그램 연동**: 전문계정이 아직 없어 코드는 만들지 않았습니다. `docs/CHECKLIST.md`의 개설 순서를 먼저 진행해 주세요.
- **자동 공개**: 업로드는 항상 비공개. 공개 전환은 `publish.py verify`로 사람이 확인한 뒤에만.
- **의료·여행상품 판매·다국어 확장**: 계획서 34·44·48쪽에 따라 별도 검토 전 비활성.
- 자산 등록·검수 화면(관리자 UI)은 다음 단계. 지금은 Supabase Studio에서 직접 입력합니다.

## 미니 포털 (v0.2)

홈 화면이 여러 매체의 여행 콘텐츠를 모아 요약하는 포털로 바뀌었습니다.

| 영역 | 하는 일 |
|---|---|
| 히어로 | 해변·현수교·도시가 움직이는 장면. `HERO_VIDEO_URL` 이 있으면 그 영상으로 교체 (권리 승인된 영상만) |
| 매체 탭·띠 | 쇼츠·릴스, 영상, 블로그, 공식 안내, 판단 문서별로 걸러 보기. 방금 정리된 이야기가 흐르는 띠 |
| 바다↔도시 다이얼 | 끌면 분위기가 가까운 이야기부터 다시 정렬 |
| 컬렉션 | 편집팀이 여러 매체를 하나의 여행 질문으로 묶은 것 |
| 상세 시트 | 편집 요약, 근거 상태, 제휴 표시, 원본으로 이동 |

**포털이 지키는 규칙 (DB에서 강제, 12건 검증)**
- 요약은 협약으로 요약을 허락받은 출처나 자사 채널만 공개. 아니면 제목과 "요약하지 않은 이유"만 노출
- 요약 허락을 철회하면 피드 요약이 즉시 내려가고, 협약이 끝나면 피드·컬렉션에서 빠짐
- 썸네일은 권리 승인 자산만. 없으면 화면이 일러스트 포스터를 그림 (이미지 파일 불필요)
- 의료 관련 장소 콘텐츠는 승인 불가
- 자사 유튜브 쇼츠가 실제 공개되면 피드 후보로 자동 등록 → 편집팀 승인 후 노출

**히어로 영상을 쓰려면**: 영상을 `assets`에 등록해 권리를 승인받은 뒤, 공개 주소를 Coolify 환경변수 `HERO_VIDEO_URL`(과 선택적으로 `HERO_VIDEO_POSTER`)에 넣습니다. 15~20초, 1080p 이하, 음성 없는 H.264 MP4 권장(2~4MB).

## 롱폼 운영 (v0.3, 서비스기획서 5장)

롱폼은 따로 기획하지 않고 **공개된 쇼츠를 기준에 따라 묶어 새 해설을 더해** 만듭니다.

| 기준 (기본값, `longform_settings`에서 조정) | 값 |
|---|---|
| 채널 공개 쇼츠 누적 | 30편 |
| 묶음(같은 지역, 또는 질문 유형 × 테마) | 8편 |
| 공개 후 관측 기간 | 14일 |
| 근거 재확인 주기 | 90일 |
| 자산 사용 기한 여유 | 30일 |

- `select * from trip.longform_candidates;` → 착수 가능한 묶음과 부족한 조건
- 승인 차단: 기준 미달 쇼츠, 다른 묶음 섞임, 롱폼 사용 범위 재확인 누락, 새 해설 없는 챕터, 미해결 정정, 협찬 표시 누락
- 업로드: `python integrations/youtube/publish.py longform LF-0001 --dry-run` → 비공개 업로드 → `--make-public`
